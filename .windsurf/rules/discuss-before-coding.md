Before writing or modifying any code, always discuss and confirm the proposed solution.

- Do **not** start coding immediately when a new feature or task is mentioned.
- Instead, ask clarifying questions and propose a few implementation options.
- Wait for me to **explicitly confirm** with phrases like:
  - "Let's start coding"
  - "Go ahead and implement"
  - "Please write the code now"
- Until I say one of those, focus only on understanding the problem, exploring approaches, and reviewing trade-offs.

This rule applies to all features, refactorings, and technical improvements.
